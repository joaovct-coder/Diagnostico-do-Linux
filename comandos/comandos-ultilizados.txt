1. Sinais (PID 11537, Isolated Web Co)
$ kill -STOP 11537

$ ps -p 11537 -o pid,stat,comm
    PID STAT COMMAND
  11537 Tl   Isolated Web Co

$ kill -CONT 11537

$ ps -p 11537 -o pid,stat,comm
    PID STAT COMMAND
  11537 Sl   Isolated Web Co

$ ps -p 11537 -o pid,ppid,stat,ni,%cpu,%mem,comm
    PID    PPID STAT  NI %CPU %MEM COMMAND
  11537   11113 Sl     0  1.4  4.3 Isolated Web Co

$ kill -TERM 11537

$ ps -p 11537 -o pid,stat,comm
    PID STAT COMMAND

Depois do kill -TERM só o cabeçalho apareceu, então não havia mais processo com esse PID.

Comandos de nice

Ver o nice atual de um processo:

bash
ps -p PID -o pid,ppid,stat,pri,ni,%cpu,%mem,comm

Alterar o nice de um processo em execução (renice):

bash
renice -n 5 -p PID

Valores positivos (até 19) pedem menos prioridade de CPU. Qualquer usuário pode aumentar o nice dos próprios processos.
