1. Sinais (PID 11537, Isolated Web Co)
$ kill -STOP 11537

$ ps -p 11537 -o pid,stat,comm
    PID STAT COMMAND
  11537 Tl   Isolated Web Co

$ kill -CONT 11537

$ ps -p 11537 -o pid,stat,comm
    PID STAT COMMAND
  11537 Sl   Isolated Web Co

$ ps -p 11537 -o pid,ppid,stat,ni,%cpu,%mem,comm
    PID    PPID STAT  NI %CPU %MEM COMMAND
  11537   11113 Sl     0  1.4  4.3 Isolated Web Co

$ kill -TERM 11537

$ ps -p 11537 -o pid,stat,comm
    PID STAT COMMAND

Depois do kill -TERM só o cabeçalho apareceu, então não havia mais processo com esse PID.
